## 题记

> **离 Marx 越远，离 Marx 越近。**
>
> 回到马克思主义，不是退回到过去，而是在当代资本主义新的现实矛盾中，重新发现马克思主义中被遮蔽、隐藏、修正的批判性力量。
>
> 让哲学从哲学家的*课堂*上和*书本*里*解放出来*，变为群众手里的尖锐武器。

## 这个 Skill 能做什么

Marxism Skill 为 Agent 提供马克思、恩格斯原著，以及阅读、理解和讨论这些原著的方法。围绕你的问题，Agent 使用自己的文件搜索与阅读工具查读材料，从具体论述中梳理概念、前提和理由，逐步建立对经典马克思主义思想体系的理解。

- **回到原著。** 从作品的实际文本中查找相关段落，连同上下文阅读，回答中给出作品与章节出处。
- **把思想联系起来。** 追踪概念在不同著作中的用法，比较各篇讨论的问题和论证，理解观点之间怎样建立联系。
- **把讨论推进下去。** 从通俗解释开始，随着追问展开理由、回应异议、比较材料，讨论理论与现实问题之间的关系。

你可以带着一个生活中的困惑开始，也可以带来一段读不懂或不认同的原文。解释的详略随交流调整，讨论始终可以回到原著核对。

## 从现实问题开始

安装后，可以把下面任意一个问题交给 Agent，并指定使用 `marxism-skill`。下面的回答节选来自 DeepSeek Harness 中使用 `deepseek-flash` 的实际对话。

1. 效率提高了，为什么反而更忙？生产力的发展没有让工人少干，反而带来了更多任务并加强了对工人的支配。为什么会出现这种现象？

   <details>
   <summary>查看实际回答节选</summary>

   > 支配的加强则更深一层，不能只理解为老板变得更凶。机器把技巧从工人身上转移到机器上，工人就从“利用工具”变成“服侍机器”，“死机构独立于工人而存在，工人被当作活的附属物并入死机构”（第十三章）。科学、自然力、大规模协作这些本来属于人类的能力，体现在机器体系里，作为“主人”的权力同工人相对立。再加上工厂法典、监工、罚款和兵营式的纪律，“资本在工厂法典中却通过私人立法独断地确立了对工人的专制”。资本不仅规定劳动多久，还规定怎样动、动多快、听谁指挥。这就是劳动过程本身被改造，而不仅是在劳动过程之外增加规定。

   </details>

2. 生产力发展到一定程度，人类就不再需要劳动了吗？以当下的 AI 为例，有人认为技术进步最终能替代人的劳动，让所有人自由生活。这种想法是否合理？

   <details>
   <summary>查看实际回答节选</summary>

   > 所以“让所有人自由生活”这句话里的“所有人”才是问题所在。生产力可以做到“足够所有人”，但“所有人”能否分享，不取决于机器能生产多少，而取决于谁拥有机器、谁支配省下来的时间。用马克思的框架说，技术是生产力，但生产力释放出来的时间怎样分配，要经过生产关系这道关口。马克思在《哥达纲领批判》第一部分里讲“按需分配”时，前面有一串条件：迫使个人奴隶般地服从分工的情形消失、脑力劳动和体力劳动的对立消失、劳动“不仅仅是谋生的手段，而且本身成了生活的第一需要”。这些条件没有一条是技术自动提供的。恩格斯讲得更直接：未来社会要消灭旧的分工，使劳动“从一种负担变成一种快乐”——注意，是变成快乐，不是变成没有。

   </details>

3. 过度劳动是时代生产力发展所必需的牺牲吗？在当今，一些劳动者长期过度劳动，工作与个人生活失衡，有人用“时代需要牺牲”来解释。请分析这种现象为何产生，以及这种解释是否成立。

   <details>
   <summary>查看实际回答节选</summary>

   > 马克思确实说过：“在资本主义制度内部，一切提高社会劳动生产力的方法都是靠牺牲工人个人来实现的。”（《资本论》第一卷）他也说过：“没有对抗就没有进步。这是文明直到今天所遵循的规律。到目前为止，生产力就是由于这种阶级对抗的规律而发展起来的。”（《哲学的贫困》）生产力在历史上并不是在普遍受益中平稳增长的，它确实以一部分人承担代价、另一部分人占有成果的方式前进。这个判断来自马克思，并非为这种现象辩护的人发明。
   >
   > 但要注意两个限定词：“在资本主义制度内部”，以及“到目前为止”。

   </details>

4. 赚钱时没我的份，亏钱时为什么要一起承担？企业常用“利益共同体”来绑定员工与公司，但双方在收益、风险和决定权上存在差别。请分析这种叙事成立的条件，以及它可能掩盖的矛盾。

   <details>
   <summary>查看实际回答节选</summary>

   > 马克思并不否认资本和劳动相互依赖。《雇佣劳动与资本》把这个前提说得很直白：资本不雇工，工人活不下去；资本不剥削劳动力，资本也活不下去。所以"利益共同"有一个真实的内核。但他紧接着说，这不过是表明"资本和雇佣劳动是同一种关系的两个方面"，就像高利贷者和挥霍者相互制约——一方是权力，一方是依赖。他引用得最直接的一句是："只要雇佣工人仍然是雇佣工人，他的命运就取决于资本。这就是一再被人称道的工人和资本家利益的共同性。"
   >
   > 依赖是不对称的：企业少了某个工人可以再招，工人离开整个雇佣关系却无处可去，"工人不是属于某一个资本家，而是属于整个资本家阶级"。因此，这里实际成立的是依赖关系，而不是合伙关系。
   >
   > ……
   >
   > 所以判断一句"利益共同体"是承诺还是修辞，不必听它讲得多好，看三件事：赚钱时有没有可执行的分成，做决定时有没有席位，退出时有没有底气。三样都没有，"共担"就只是"你承担"的客气说法。

   </details>

## 如何使用

**1. 安装整个 Skill。** 下载或克隆本仓库，将整个 `marxism-skill/` 目录放入所用 Agent 的 Skill 目录；也可以使用该 Agent 提供的仓库安装方式。入口是根目录的 [SKILL.md](SKILL.md)，`references/` 随目录一起保留。

**2. 带着问题开始。** 安装后，可以这样发起对话：

```text
使用 marxism-skill，围绕下面的问题查读原著并和我讨论，给出作品与章节出处：

（粘贴你想讨论的问题）
```

**3. 沿着疑问继续。** 可以继续追问某一步为什么成立、比较不同作品的说法，或要求用更通俗的语言解释。

Skill 使用宿主 Agent 自己的文件搜索和阅读能力；无需运行维护脚本、部署额外检索服务或启动 Mind Spark。
