# Marxism Skill

让 Agent 自己读马克思、恩格斯原著，理解和讨论经典马克思主义。

本仓库本身就是一份完整Skill，包含原著、按主题组织的阅读指引，以及如何使用材料的说明。Agent使用自己的文件搜索和阅读工具查读，不依赖Mind Spark或专用检索服务。

## 使用

下载或克隆本仓库，将整个`marxism-skill`目录放进目标Agent支持的Skill目录；也可以用它的仓库安装功能安装。入口是根目录的[SKILL.md](SKILL.md)，不要只复制这个文件，`references/`也需要一起保留。

安装后可以这样提问：

> 使用marxism-skill，依据实际读过的原著解释异化劳动与私有财产的关系，给出作品和章节出处。

也可以核对引文、比较不同著作，或询问阅读顺序。无需安装Python、运行构建命令或启动Mind Spark。

## 内容

```text
marxism-skill/
├─ SKILL.md                 Agent使用入口与材料使用约束
├─ README.md                安装和使用说明
└─ references/
   ├─ reading-guide.md      主题与阅读指引
   ├─ catalog.md            作品目录、作者与版本
   ├─ chapters.md           原著章节与行号定位
   ├─ works/               马克思、恩格斯及合著原文
   └─ checks/              原著仍需的公式等图片附件
```

当前有113份选定文本，涵盖哲学、政治经济学和科学社会主义；以中文译本为主，部分采用德文原文。这不是全集，也尚未收录列宁等后续作者。作品按作者存一份，同一作品可由不同主题指引引用。

[书目](references/catalog.md)用于找作品，[阅读指引](references/reading-guide.md)用于选阅读方向，[章目](references/chapters.md)用于定位原著。回答应依据实际读过的原著，区分原文、归纳和进一步分析，不把导读当作理论证据。

《1861—1863年经济学手稿》仍有未文字化的公式图片；个别作者索引沿用既有OCR。这些限制及采用版本见[SKILL.md](SKILL.md)和对应作品说明，不能把目录存在当作全文已可纯文字读取。

来源、版本和出版信息保留在各作品中。材料公开可读不代表所有译本采用同一许可证；本仓库目前未为全部内容声明统一许可。
