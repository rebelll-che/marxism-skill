# Marxism Skill

让 Agent 自己读原著，依据马克思、恩格斯的材料理解和讨论马克思主义。

本仓库提供选定原著的电子整理稿、阅读指引和使用约束。Agent使用自己的文件搜索与阅读能力，不需要启动Mind Spark，也不需要专用检索服务。导读用于找到原著，不用预写的二手答案替代原著。

## 当前范围

当前收录113份选定文本：马克思79份、恩格斯26份、合著8份，涵盖哲学、政治经济学和科学社会主义的主要论述，以及有关的历史分析、理论书信、手稿和序导言。以中文译本为主，部分材料含外文。

这不是全集，也不宣称完整收齐经典马克思主义。尚无列宁等后续作者；以私生活、出版联络为主且缺少理论内容的材料不在当前范围内。一部作品只保存一份主用文本，独立草稿、实质修订和不同序言按文献性质区分，不把同一理论材料复制到多个主题目录。

## 当前来源与文字检查结果

当前113份活动文本中，原来107份已按可靠来源、章节首尾和少量正文检查通过基本文字使用检查；这不等于逐字校勘无误。《英国工人阶级状况》的三幅街区/住宅布局图及《自然辩证法》的两幅科学示意图按知识库用途省略，相关原著文字保留并标明位置。

《1857—1858年经济学手稿》已改用BBAW官方MEGA II/1两个分册的完整现存德文文字，公式、表格均可直接读；1843年《黑格尔法哲学批判》已改用MEW第1卷同版五部分的完整现存德文正文。两份正文不混用其他版本补缺；旧合稿内的两个作者索引和1858年独立初稿分别保存，因拆分增加3个文件，没有重复收录同篇译本。其中《黑格尔法哲学批判》作者索引的两页中文文字仍来自既有OCR，已注明限制，不据此改写正文。

仍需换源的是《1861—1863年经济学手稿》：当前稿由中文各部分与德文第五部分组成，3525张图片尚未全部文字化。尚未取得足以替换其全部现存范围的统一、完整、直接可读文字版，本轮保留并明确限制，不因其他文字入口只覆盖部分内容而称为完成替换。

检查采用项目约定的基本质量标准，不重复全库校勘、不新做OCR或图片转写、不调用收费模型。原107份核对过129个MIA文字网页；本次仅对两份替换稿及分出的文献定向核查。细节保存在本地`collection/checks/material-review/`和`collection/checks/unified-text-import/`，不随Skill安装。更换作品正文不等于验证所有问题下的模型理解效果。

## 安装和使用

```sh
git clone https://github.com/rebelll-che/marxism-skill.git
```

将仓库中的**完整`marxism-skill/`文件夹**放入目标Agent支持的Skill目录，或通过它支持的仓库安装方式选择这个子目录。不要只复制`SKILL.md`，也不需要把`tools/`、`tests/`或收集缓存装进Agent。具体安装位置以所用Agent的说明为准。

可以这样提问：

> 使用marxism-skill，依据实际读过的原著解释异化劳动与私有财产的关系，给出作品和章节出处。

也可以要求核对一个引文、比较不同作品中的论述，或先推荐阅读顺序。Skill要求区分原文、归纳和进一步分析，不编造历史作者的观点；找不到材料时应说明限制。它提供阅读约定，不能保证所有模型每次理解正确。

## 文件怎样组织

```text
marxism-skill/
├─ SKILL.md                      Agent使用入口
└─ references/
   ├─ reading-guide.md            按思想主题组织的阅读入口
   ├─ catalog.md                  作品、作者、版本与文件路径
   ├─ chapters.md                 原有章节层级和原文件行号
   ├─ works/
   │  ├─ marx/                    马克思作品
   │  ├─ engels/                  恩格斯作品
   │  └─ marx-engels/             合著
   ├─ assets/                     原文附件
   ├─ sources/                    原文附件
   └─ checks/                     原文引用的图片等附件
```

作品按作者存储；哲学、政治经济学、科学社会主义等主题在导读中组织，同一作品可以被多个主题引用。`catalog.md`和`chapters.md`由工具生成，不是理论依据；实际回答应回到`works/`中的原文。材料有原始章节、版本和来源说明，应注意区分作者正文、引用、修订者和编者说明。

当前仍保留3525张图片，全部属于《1861—1863年经济学手稿》；其他112份文本无图片引用。此次两份正文换源并拆分独立文献后，移出816个已被替代的图片文件，旧图在维护资料中留存并核对哈希。1857—1858年手稿的1088个原生MathML公式转为LaTeX，33张表格保留行列和合并单元格；22幅手稿书影及其图片说明不随文字稿提供，没有用猜测的计算代替原著。

本库按理论阅读用途筛选附件，不无条件复刻全部插图，也不以删去理论计算来解决图片问题。Agent用普通文字工具读Markdown不会自动看图；确需1861—1863年手稿内仍未文字化的计算、且宿主支持看图时，再打开相应图片。不能读取时应说明限制。先前文本问答试用不能证明图片理解能力，完整的附件处理历史见CHANGELOG。

Markdown头部的`source_file`、`source_sha256`保留此前转换原件的位置与哈希；历史下载原件不随Skill公开，核对出处时使用同一头部的公共`source`地址及文献说明。这些历史路径不表示包内有可直接打开的PDF。

全部文本使用UTF-8。Windows工具如显示乱码，请以UTF-8模式重读，例如`python -X utf8`；文件行号按原始LF计算并包含YAML头，不是书本页码。Agent按问题读取必要材料即可，不需要加载完整目录或整库正文。

## 维护和验证

原著、附件、Skill指令和导读在本仓库维护。修改规则见[AGENTS.md](AGENTS.md)，重要变化见[CHANGELOG.md](CHANGELOG.md)。普通使用者无需安装下面的维护依赖。

维护工具只需Python、PyYAML；自动检查另外需要pytest：

```sh
python -m pip install PyYAML pytest
python -X utf8 tools/build_skill.py
python -X utf8 tools/build_skill.py --check
python -X utf8 -m pytest -q
```

第一条工具命令仅刷新作品和章节目录；`--check`只检查，不修改原文或指引。工具直接读取本仓库的原著，不依赖Mind Spark的清单、SQLite、API Key或运行数据。具体Python版本见`pyproject.toml`。

已有原生Codex CLI在本机完成入口、书目和原著读取及带出处回答，另有概念、版本区分和跨作品查读试用；这证明当前Skill初步可用，不等同于所有客户端、模型或问题都已验证。此次独立仓库拆分复用这些内容试用，另做文件、导航和独立运行检查，不为迁移重复调用在线模型。

## 与Mind Spark的关系

本仓库是选定原著和外置Skill的唯一维护源。[Mind Spark](https://github.com/rebelll-che/mind-spark)是基于这些材料的桌面对话应用；它在构建时导入一个明确的Git提交并生成自己的本地索引，随应用一起打包，运行时不自动追踪本仓库的新材料。两个项目分别管理版本。

## 来源与许可说明

目前两份已换源的正文均使用德文原文：

- 1857—1858年手稿：[BBAW/MEGAdigital](https://telota.bbaw.de/mega/)公开MEGA II/1[第一分册文字数据](https://telota.bbaw.de/mega/docs/MEGA_A2_B001-01_ETX.xml)和[第二分册文字数据](https://telota.bbaw.de/mega/docs/MEGA_A2_B001-02_ETX.xml)，含《巴师夏和凯里》《导言》及现存手稿末尾“金称量机”摘录；两分册分别出版于1976、1981年，同属一个版本。
- 1843年《黑格尔法哲学批判》：[MEW第1卷1976年版文字](https://marx.works/me01/me01_203.htm)，按原页的五部分合并，书203—333页，对应现存§261—313；不混入1844年《导言》。原稿前部失存和末尾未完成不算下载遗漏。
- 1861—1863年手稿：[MIA英文手稿入口](https://www.marxists.org/archive/marx/works/1861/economic/index.htm)及[《剩余价值理论》](https://www.marxists.org/archive/marx/works/1863/theories-surplus-value/index.htm)可辅助定向对照，尚未确认能等范围替代当前六部分合稿。目录列有标题不代表对应正文已经可取，也不能将选编充作全部手稿。

原生文字网页仍可能有录入错误；选择它们不免除章节范围、首尾及少量正文的检查。采用完整统一版本的要求针对每份独立文献，单独分出的作者索引和初稿仍明确各自的中文版本，不冒充德文正文的一部分。

各作品保留既有来源、版本及文献性质说明。仓库尚未为所有内容选定统一许可证，不把维护脚本的许可或材料公开可读理解为覆盖所有原著译本的统一许可。
